V5 关键变化

  • 关键词分层 S/A/B + 质量分，默认 final ≥ 6
  • c2 / rce / 0day 禁止单独过线
  • 工具监控改为 pushed_at / release 变更检测
  • 新增 Skill 发现推荐（SkillHub + GitHub + Seed）
  • 历史噪声归档到 data/archive/
  • 关键词自动建议：python -m monitor.run --suggest-keywords --publish
  • 描述优先显示中文 description_cn（多源翻译）

当前关键词分层

配置文件：config/keywords.yaml

  • S 精确：工具/技术专名，可单独过线（约 54 词）
  • A 上下文：歧义词，需安全上下文或叠词（约 21 词）
  • B 泛化：宽泛词，只加成（约 34 词）

建议流程：跑 --suggest-keywords → 在「关键词建议」页审阅 → 人工写入 keywords.yaml → 再跑 daily。
